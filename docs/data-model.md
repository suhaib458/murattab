# نموذج البيانات

`StudentProfile` يرتبط بإعداد الجامعة والكلية والتخصص. `AcademicTerm` يحد الجلسات المتكررة. `Course` له جلسة أو أكثر (`ClassSession`) عبر `courseId`. الجلسة تخزن اليوم ووقت 24 ساعة والقاعة والنوع؛ العرض يحولها إلى 12 ساعة عربيًا.

كل النماذج لها TypeScript وZod في `src/domain/models.ts`. النسخ الاحتياطي يضم `schemaVersion` ووقت التصدير والبيانات اللازمة ويُتحقق منه قبل أي استبدال.
