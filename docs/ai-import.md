# استيراد الجدول بالذكاء الاصطناعي في «مرتب» (Smart Schedule Import)

تم تنفيذ ميزة استيراد الجدول الذكي لطلبة جامعة الطفيلة التقنية وفق أعلى معايير الخصوصية والموثوقية وتجربة المستخدم RTL.

## 1. المعمارية العامة وتدفق البيانات
- **واجهة المستخدم (Client)**:
  - نافذة منبثقة تفاعلية `ImportDialog` تدعم السحب والإفلات ومعاينة الملفات (JPG, PNG, WebP, PDF حتى 10MB).
  - موافقة صريحة وإلزامية قبل الإرسال مع توضيح سياسة الخصوصية.
  - شاشة تقدم التحليل التفاعلية مع دعم إلغاء العملية (`AbortController`).
  - شاشة مراجعة شاملة للجدول المستخرج تعرض أسماء المواد، نوع الجلسة (نظري/عملي)، الأيام، الأوقات بنظام 24 ساعة، والقاعات مع توسيع الرموز تلقائيًا (مثل: `207 م` -> `مبنى المجمع`).
  - مؤشرات درجات الثقة (عالية / تحتاج انتباه) وقائمة الملاحظات والمشاكل المكتشفة.
  - دعم معالجة التكرار (استبدال / إبقاء الاثنين / تخطي) واكتشاف التعارضات الزمنية.
  - حفظ ذري دفعة واحدة (Atomic Batch Save) في التخزين المحلي (IndexedDB / Dexie) بدون أي حفظ تلقائي مباشر.

- **الخادم (Server Route Handler)**:
  - مسار `POST /api/schedule/extract` يعمل على بيئة `nodejs` حصراً.
  - مفتاح `GEMINI_API_KEY` محمي في بيئة الخادم فقط ولا يُسرب للعميل أو حزم JS.
  - التحقق الصارم من الحجم والنوع والموافقة الصريحة.
  - حذف ومعالجة البيانات في الذاكرة المؤقتة فقط دون أي حفظ دائم للملفات أو صور الطلاب.

## 2. قواعد جامعة الطفيلة التقنية المطبقة (TTU Domain)
- دعم وتوسيع رموز القاعات والمباني المعتمدة في النظام التأسيسي (Foundation):
  - `م`: مجمع القاعات
  - `هـ` أو `ه`: كلية الهندسة
  - `ع`: كلية الأعمال
  - القاعات والرموز غير المعروفة: تبقى بنصها الأصلي الخام (raw text) ولا يتم تخمين أي مبنى.
- ضبط أيام الدوام الرسمية ورموزها:
  - الأحد (`ح`)، الإثنين (`ن`)، الثلاثاء (`ث`)، الأربعاء (`ر`)، الخميس (`خ`)، والسبت (`س`).
  - دعم قراءة الأيام الحقيقية ودمجها مثل: (ح، ث، خ) و (ن، ر).
- قواعد منع التخمين والافتراضات الصامتة (Strict Non-Inference):
  - لا يتم افتراض أي يوم افتراضي (مثل الأحد) عند غياب اليوم، بل يُترك غير محدد (`null`) ويطلب تصحيحه.
  - لا يتم افتراض وقت بدء تلقائي (مثل 08:30) عند غيابه، بل يُترك غير محدد (`null`).
  - لا يتم تخمين وقت الانتهاء بناءً على مدد افتراضية (60 أو 90 دقيقة)، بل يُترك غير محدد عند غيابه.
  - لا يتم افتراض أن الأوقات (1–6) بدون دلالة صباح/مساء هي مسائية تلقائياً.
  - لا يتم اختراع أسماء مواد بديلة (مثل "مادة غير مسماة")، بل يُترك الاسم فارغاً ويُنبّه الطالب لإدخاله.
  - حظر الاعتماد النهائي لأي مسودة تحتوي على حقول إلزامية غير مكتملة حتى تصحيحها من قِبل الطالب.

## 3. الأمان والخصوصية
- لا توجد حسابات أو مزامنة سحابية.
- المعالجة سريعة وزائلة (ephemeral).
- في حال غياب مفتاح API يتم إرجاع رمز 503 مع رسالة عربية واضحة وودية.
