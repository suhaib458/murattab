# إشعارات الجهاز

تعمل إشعارات «مرتب» عبر Web Push. يوافق المستخدم مرة واحدة على كل جهاز، ثم يخزّن الخادم اشتراك الجهاز والتذكيرات المطلوبة فقط. لا يُخزَّن اسم الطالب أو رقمه الجامعي أو ملفه الأكاديمي.

## البنية

- المتصفح ينشئ رمز جهاز عشوائيًا واشتراك Push محميًا.
- واجهات `/api/push/*` تتحقق من رمز الجهاز وتتواصل مع Supabase من الخادم فقط.
- Supabase يحفظ الأجهزة والتذكيرات مع RLS ومن دون صلاحيات مباشرة لـ `anon` أو `authenticated`.
- Supabase Vault يحتفظ بسر استدعاء الـ dispatcher، بينما تحفظ قاعدة البيانات بصمة SHA-256 فقط للتحقق منه.
- Supabase Cron يستدعي `/api/push/dispatch` كل دقيقة.
- عامل الخدمة `public/sw.js` يعرض الإشعار ويفتح الصفحة المحددة عند الضغط عليه.
- مفتاح Supabase السري يبقى على Vercel فقط ولا يصل إلى المتصفح.

## الإشعارات العامة

ميزة Broadcast تسمح لأجهزة الإدارة المصرح لها بكتابة عنوان ونص إشعار واحد وإرساله لكل الأجهزة التي فعّلت إشعارات «مرتب».

- أجهزة الإدارة محفوظة في `push_admin_devices`.
- لوحة الإرسال لا تظهر على الأجهزة العادية.
- الطلب يحتاج رمز الجهاز العشوائي الصحيح بالإضافة إلى وجود الجهاز في قائمة الإدارة.
- كل Broadcast يُحفظ مرة واحدة في `push_broadcasts`.
- قاعدة البيانات تنشئ Delivery مستقل لكل جهاز مفعّل في `push_broadcast_deliveries`.
- الـ dispatcher يرسل الدفعات ويعيد المحاولة حتى 5 مرات عند الأخطاء المؤقتة.
- الاشتراكات المنتهية أو الملغاة تُحذف عند رجوع 404 أو 410 من مزود Web Push.

إضافة جهاز إدارة هي خطوة تشغيلية خاصة ببيئة الإنتاج ولا توضع معرّفات الأجهزة داخل Git:

```sql
insert into public.push_admin_devices (device_id)
values ('<registered-device-uuid>')
on conflict do nothing;
```

## متغيرات Vercel

يلزم في Vercel:

```text
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
VAPID_PUBLIC_KEY=
VAPID_PRIVATE_KEY=
```

`VAPID_SUBJECT` اختياري. على Vercel يتم اشتقاقه تلقائيًا من رابط المشروع الإنتاجي.

لا يوجد متغير `PUSH_DISPATCH_SECRET` على Vercel؛ سر الـCron يتولد داخل Supabase Vault ولا يغادر قاعدة البيانات.

## قاعدة البيانات

المهاجرات المطلوبة:

- `202609210001_push_notifications.sql`
- `202609210002_push_dispatch_security.sql`
- `202609210003_push_broadcasts.sql`

قاعدة الإنتاج تحتاج أيضًا إعدادًا تشغيليًا مرة واحدة لإنشاء سر Vault وجدولة `murattab-push-dispatch` وتحديد أجهزة الإدارة. لا يجب حفظ الأسرار أو معرّفات أجهزة الإدارة الخاصة ببيئة الإنتاج في Git.

## ملاحظات الأجهزة

- Android وChrome وEdge وFirefox: يعمل بعد موافقة المستخدم.
- iPhone/iPad: يلزم iOS/iPadOS 16.4 أو أحدث، وتثبيت «مرتب» على الشاشة الرئيسية، ثم تفعيل الإشعارات من داخل التطبيق.
- لا يمكن لأي موقع تفعيل إشعارات الجهاز من دون موافقة المستخدم؛ هذا قيد أمان من نظام التشغيل.
