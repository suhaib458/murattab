# توثيق ميزة استيراد الجدول الذكي (Smart Schedule Import)

## نظرة عامة
تتيح ميزة استيراد الجدول الذكي لطلبة جامعة الطفيلة التقنية تحويل صور الجداول الدراسية أو ملفات PDF إلى جدول رقمي تفاعلي محلي داخل تطبيق «مرتب»، مع الحفاظ التام على خصوصية الطالب ومبدأ Local-first.

---

## تدفق تجربة المستخدم (User Experience Flow)
1. **بدء الاستيراد**:
   - يتوفر زر "استيراد الجدول" في الشاشة الرئيسية (Home) وشاشة الجدول الأسبوعي (Schedule).
2. **الرفع والموافقة الصريحة**:
   - رفع صورة (JPG, PNG, WebP) أو ملف PDF (حتى 10MB).
   - عرض اسم وحجم ونوع الملف مع إمكانية إزالته أو استبداله ومعاينة الصور مباشرة.
   - موافقة صريحة عبر Checkbox لتأكيد إرسال الملف للتحليل لغرض استخراج الجدول فقط.
3. **التحليل ومؤشر التقدم**:
   - ظهور شاشة مؤشر التحميل المتدرج مع زر "إلغاء التحليل" لإيقاف الطلب فوراً عبر `AbortController`.
4. **المراجعة والتحرير الشامل**:
   - عرض بطاقات المواد المستخرجة مع إمكانية تعديل الاسم، نوع الجلسة (نظري/عملي)، الأيام، الأوقات، والقاعات.
   - كشف التكرار مع المواد المسجلة مسبقاً وتخيير الطالب بين (استبدال / إبقاء الاثنين / تخطي).
   - كشف التعارضات الزمنية وعرض تنبيه واضح وإلزام الطالب بتأكيد حفظ التعارض في حال رغب بذلك.
   - إمكانية حذف أي جلسة أو مادة وإضافة مواد مفقودة يدوياً.
   - شريط الملاحظات الذكية ودرجات الثقة المنخفضة لتوجيه انتباه الطالب للحقول التي قد تحتاج تدقيقاً.
5. **الاعتماد والحفظ الذري**:
   - عند النقر على "اعتماد الجدول"، يتم حفظ جميع المواد والجلسات دفعة واحدة في عملية ذرية (Atomic Batch Save) محلياً داخل IndexedDB/Dexie.

---

## التكامل والنموذج المعماري (Architecture)
- **عزل طبقة الخادم**:
  - معالجة التحليل تتم عبر مسار خادم Next.js Route Handler في `src/app/api/schedule/extract/route.ts` ببيئة Node.js فقط.
  - مفتاح `GEMINI_API_KEY` مستدعى من متغيرات البيئة الخادمة حصراً، ولا يتم تضمينه في حزم العميل مطلقاً.
- **التطبيع الخاص بجامعة الطفيلة التقنية**:
  - `src/domain/ai/normalizer.ts`: تطبيع الأيام والرموز (`ح، ن، ث، ر، خ، س`) وتحليل الأوقات (24h) وتوسيع رموز المباني المعتمدة فقط (`م`: مجمع القاعات، `هـ/ه`: كلية الهندسة، `ع`: كلية الأعمال)، مع إبقاء أي رموز غير معروفة بنصها الأصلي دون تخمين.
  - دعم مسودات المراجعة غير المكتملة (Unresolved Drafts): الحقول المفقودة (مثل اليوم، وقت البدء، وقت الانتهاء، اسم المادة) تُمثّل كقيم غير محددة ولا يتم اختراعها أبداً، مع حظر الحفظ النهائي حتى يستكمل الطالب الحقول الإلزامية.
- **الحفظ الذري**:
  - دالة `saveCourses` في `ScheduleRepository` و `LocalScheduleRepository` لتنفيذ الحفظ المجمّع داخل عملية ذرية واحدة لضمان سلامة واتساق البيانات.

---

## الأمان والخصوصية (Privacy & Security)
- لا توجد قواعد بيانات خارجية تحفظ ملفات الطلاب؛ معالجة الملف مؤقتة وعابرة (in-memory ephemeral buffer).
- إرجاع خطأ 503 واضح وودود في حال عدم توفر مفتاح الذكاء الاصطناعي في البيئة.
- لا توجد حسابات أو مشاركة بيانات مع جهات خارجية غير مزود التحليل المعتمد بعد موافقة الطالب.
