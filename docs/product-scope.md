# نطاق MVP

يدخل: PWA عربي RTL، تشغيل أول، ملف محلي، جدول يدوي، عرض يومي/أسبوعي/شهري، تصدير ICS، نسخة احتياطية JSON، وضعان فاتح وداكن، وإشعارات جهاز اختيارية للمحاضرات.

لا يدخل: الحسابات، مزامنة الملف والجدول بين الأجهزة، API الجامعة، العلامات، المهام، المجتمع أو الأصدقاء. تستخدم إشعارات الجهاز تخزينًا سحابيًا محدودًا لاشتراك الجهاز وتفاصيل التذكيرات فقط، بعد موافقة المستخدم.
